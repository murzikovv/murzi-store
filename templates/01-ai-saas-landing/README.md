# Beacon — AI / SaaS Landing Page Template

A precision, production-ready one-page landing template for an AI, SaaS, or developer-tool product. Distinctive "instrument / blueprint" aesthetic: committed cobalt on pure white, an amber signal accent, one drenched dark band, and a custom-built animated dashboard mockup (no stock photos, no placeholders).

**Live demo:** open `index.html` in any browser.

---

## What you get

- **One self-contained `index.html`** — no build step, no framework, no npm install. Edit and ship.
- **Zero dependencies** except Google Fonts (Bricolage Grotesque + Spline Sans Mono).
- **Full landing structure:** sticky nav, hero with live SVG dashboard, trust bar, three alternating feature rows (each with its own hand-built SVG diagram), a 3-step "how it works" sequence, a drenched dark stats band, 3-tier pricing, testimonial, final CTA, and a structured footer.
- **Custom SVG illustrations** — animated signal chart, anomaly-detection diagram, correlation timeline, ownership-routing diagram. All editable vectors, all on-brand.
- **Motion done right** — staggered reveal-on-scroll, an animating signal line, hover micro-interactions. Content is fully visible without JS; motion only enhances.
- **Accessible & responsive** — semantic HTML, ARIA labels on every graphic, AA contrast, `prefers-reduced-motion` honored, tested at 375 / 768 / 1280px.

## Rebrand in 5 minutes

1. **Colors** — open `index.html`, edit the `:root` tokens at the top of `<style>`. Every color is one OKLCH variable (`--primary`, `--accent`, `--ink`, `--bg`, `--dark`). Change `--primary` and the whole page follows.
2. **Fonts** — swap the two Google Fonts `<link>` and the `--display` / `--mono` variables.
3. **Copy** — replace the placeholder "Beacon" content with yours. Every section is plain HTML.
4. **Logo** — replace the inline `<svg class="brand__mark">` (appears in nav + footer).

## Tech

- HTML5 + modern CSS (custom properties, OKLCH, `clamp()`, grid/flex, `color-mix`).
- ~15KB of hand-written CSS, ~30 lines of vanilla JS (nav state + IntersectionObserver reveals).
- Works in all current evergreen browsers.
