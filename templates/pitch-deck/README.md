# Northstar — Investor Pitch Deck

A 12-slide seed-stage pitch deck in editable PowerPoint (`.pptx`). Built on a
Midnight Executive palette with a Georgia + Calibri pairing (both ship with
Windows and macOS — no font installs, no broken layouts).

## What's inside
`pitch-deck.pptx` — 12 ready slides, every one fully editable:

1. Cover
2. Problem (three stat callouts)
3. Solution (connect / understand / act)
4. Product (screenshot frame + features)
5. Market (TAM / SAM / SOM)
6. Business model (pricing tiers)
7. Traction (editable bar chart)
8. Competition (2×2 quadrant)
9. Go-to-market (land / expand / embed)
10. Team
11. The ask (use-of-funds)
12. Closing slide

## How to use
1. Open `pitch-deck.pptx` in PowerPoint, Keynote, or Google Slides.
2. Replace the placeholder copy, numbers and names with yours.
3. Drop your product screenshots into the dark placeholder frames.
4. Charts are native — double-click to edit the data.
