# Apex — Fitness / gym studio template

A bold, high-energy website for a strength studio, gym or boutique fitness brand — built to drive free-trial signups.

**Live demo:** open `index.html` in any browser.

## What you get
- **One self-contained `index.html`** — no build step, no framework, no npm install.
- **Zero dependencies** except Google Fonts.
- A conversion-focused layout: cinematic hero, running marquee, programs grid, a real weekly class schedule, coach profiles, three membership tiers, testimonial and a free-trial CTA. Sticky mobile action bar.
- Heavy display type (Anton) on near-black with an electric-orange charge.
- Reveal-on-scroll motion that respects `prefers-reduced-motion`, responsive at 375 / 768 / 1280px, semantic HTML and accessible contrast.

## Rebrand in minutes
1. **Name & contact** — search the file for `Apex`, `(555) 010-0142` and the address, and replace.
2. **Colours** — edit the `:root` custom properties (the accent is `--volt`).
3. **Fonts** — swap the Google Fonts `<link>` and the `--disp` / `--body` variables.
4. **Copy, schedule & images** — replace the placeholder text, the schedule table and the Unsplash image URLs with your own.
5. **Membership buttons** — point them at your booking system, Stripe links or a `mailto:` action.
