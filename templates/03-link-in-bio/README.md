# NOVA — Link-in-Bio / Creator Template

A drenched, premium "link in bio" page for a musician, creator, or any personal brand. Warm ember-and-plum aurora background, an animated equalizer status pill, a featured release card, and tappable link rows with icons. Mobile-first, but it centers beautifully on desktop too.

**Live demo:** open `index.html` in any browser.

---

## What you get

- **One self-contained `index.html`** — no build step, no framework, no backend. Edit and host anywhere (or paste into a static host).
- **Zero dependencies** except Google Fonts (Unbounded + Schibsted Grotesk).
- **Built for the format:** avatar with gradient ring, name + verified badge, bio, animated "now touring" status pill, a highlighted **featured** card (cover art + play button), four icon link rows, a social icon bar, and an email-capture field.
- **Living background** — drifting aurora glows and a fine grain overlay, all CSS/SVG, no images required.
- **Motion** — staggered entrance, hover lift on every row, animated equalizer bars. All respect `prefers-reduced-motion`.
- **Accessible & responsive** — semantic HTML, ARIA labels on icons, AA-contrast light text on the dark field, tested at 375 / 768 / 1280px.

## Rebrand in 5 minutes

1. **Identity** — replace the name "NOVA", `@novamusic`, and the bio.
2. **Colors** — edit the `:root` tokens. The mood lives in `--ember`, `--gold`, `--rose` and the `--bg` plum. Change these to retheme the whole page.
3. **Avatar & cover** — swap the two `picsum.photos` placeholder image URLs.
4. **Links** — edit the `featured` card and the four `.link` rows: icon, label, and `href`. Add or remove rows freely.
5. **Socials & email** — update the social `href`s and wire the email form to your provider (it's inert by default).

## Tech

- HTML5 + modern CSS (custom properties, OKLCH, conic/radial gradients, inline SVG grain, `clamp()`).
- Hand-written CSS, a few lines of vanilla JS for the entrance reveal.
- Works in all current evergreen browsers.
