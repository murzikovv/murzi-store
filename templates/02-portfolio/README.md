# Mara Vance — Freelancer / Portfolio Template

A bold, poster-grade one-page portfolio for an independent designer, developer, photographer, or any solo creative. Oversized condensed display type, a vermilion accent on warm white, a running marquee, and a monochrome work index that comes to life on hover.

**Live demo:** open `index.html` in any browser.

---

## What you get

- **One self-contained `index.html`** — no build step, no framework. Edit and ship.
- **Zero dependencies** except Google Fonts (Big Shoulders Display + Hanken Grotesk).
- **Full portfolio structure:** sticky nav, statement hero with portrait, animated marquee strip, a numbered "selected work" index with hover-reveal thumbnails, a two-column about with a facts table, a services section, a drenched dark contact block, and a footer.
- **Image-led** — grayscale-to-color hover on every thumbnail, designed as a deliberate monochrome system. Swap in your own work.
- **Motion** — reveal-on-scroll, a paused-on-hover marquee, smooth thumbnail and row interactions. Fully visible without JS.
- **Accessible & responsive** — semantic HTML, alt text on every image, `prefers-reduced-motion` honored, tested at 375 / 768 / 1280px.

## Rebrand in 5 minutes

1. **Your name** — replace "Mara Vance" / "MARA.VANCE" in the nav, hero, and footer.
2. **Colors** — edit the `:root` tokens. `--accent` is the vermilion; change one line to recolor the whole site.
3. **Work** — swap the five `work__item` rows: thumbnail (`<img>`), title, discipline, year. Add or remove rows freely.
4. **Images** — replace the `picsum.photos` placeholder URLs with your own image paths.
5. **Copy & contact** — update the about text, facts table, services, and the email in the contact block.

## Tech

- HTML5 + modern CSS (custom properties, OKLCH, `clamp()`, grid/flex, `-webkit-text-stroke`).
- Hand-written CSS, ~25 lines of vanilla JS (nav state + IntersectionObserver reveals).
- Works in all current evergreen browsers.
