# Ila Reyn — Photographer portfolio template

A gallery-dark portfolio for a portrait or wedding photographer: masonry work grid with a real lightbox, packages, about, and booking.

**Live demo:** open `index.html` in any browser.

## What you get
- **One self-contained `index.html`** — no build step, no framework, no npm install.
- **Zero dependencies** except Google Fonts.
- A photography-first layout: split hero, a masonry gallery with **click-to-zoom lightbox** (Esc to close), three pricing packages, an about section and a booking CTA.
- Roman display caps (Marcellus) on gallery-dark with a warm sand accent. The photographs carry the design.
- Reveal-on-scroll motion that respects `prefers-reduced-motion`, responsive at 375 / 768 / 1280px, semantic HTML and accessible contrast.

## Rebrand in minutes
1. **Name & contact** — search the file for `Ila Reyn` and `hello@ilareyn.example`, and replace.
2. **Colours** — edit the `:root` custom properties (the accent is `--sand`).
3. **Fonts** — swap the Google Fonts `<link>` and the `--disp` / `--body` variables.
4. **Photographs** — replace the Unsplash URLs with your own work; captions live in `data-cap`.
5. **Packages** — edit the three package cards; point buttons at your email, Telegram or booking form.
