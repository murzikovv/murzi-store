# Blocks — 14 copy-paste website sections

A library of hand-built website sections that work in **any** project: heroes, features, pricing, testimonials, FAQ, stats, team, newsletter, CTA and footer. Pick a theme and an accent color, press **Copy section**, paste into your page. Done.

**Live demo:** open `index.html` in any browser.

## What you get
- **14 sections** in one self-contained `index.html` — no build step, no framework, no npm install:
  2 heroes · logo strip · feature cards · feature split with checklist · stats band · 3-tier pricing · testimonials · big quote · FAQ accordion · team · newsletter · CTA band · footer.
- **Light & dark theme** — one toggle, every section follows.
- **Accent color picker** — recolor the whole library live; the contrast-safe text color is computed for you.
- **Copy section button** on every block — copies the section *plus* the shared design tokens, already in your chosen theme and accent. Paste into any HTML file and it just works.
- Consistent tokens (`--accent`, `--bg`, `--ink`, …): sections combine into full pages without fighting each other.
- Semantic HTML, responsive at 375 / 768 / 1280px, accessible contrast in both themes.

## How to use
1. Open `index.html`, pick **theme** and **accent** in the top bar.
2. Press **Copy section** on any block.
3. Paste into your page. The first paste includes the `<style>` tokens; for later sections you can delete the duplicate `<style>` block.
4. Replace the demo copy with yours. Fonts are Google Fonts (Sora + Inter); swap the `<link>` if you want different ones.
